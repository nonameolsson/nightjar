# Surface brief: nightjar ui

Scope: the `nightjar ui` page (src/ui.ts); the old look is thrown away. Mode: Operate. Visitor: a developer checking their own overnight Queue in seconds. Build path: code-led. The chosen sketch is `.impeccable/mocks/decision/assigned.html`.

Constraints: single self-contained page, no network or CDN (CSP is default-src 'none'), live updates over server-sent events, GLOSSARY terms, WCAG AA, keyboard operable. Palette is free; brand icon is reference only.

## Direction contract

THESIS: Nest Record. Each Feature is a nest watched overnight; each Ticket is an egg; Sessions are visits. The screen refuses the card-grid and CI-dashboard defaults: it is a dense ledger of nests, one row each.
OWN-WORLD: Near-black dusk ground (#12151C), bark-brown rules (#6E5A45, #2A2620), plumage buff text accents (#C9B48A), moon-white wing-flash (#F1EEE4) for needs a person, ember (#FF8A3D) for building. Egg discs with speckle shading, dashed-outline eggs for waiting. No glows beyond the one needs-a-person flash; no left-border stripes.
STORY: The person sees in seconds what is done, what is building and what needs them, then opens a nest for its Tickets and last Session.
FIRST VIEWPORT: Left rail (nightjar, Board/Table/Overview, repo and run state). Main: heading "Tonight's nests" with run state and last Session time, filter pills with counts, then a ledger with columns Feature, Tickets (egg row on a shared baseline), State, Last Session. Needs-a-person nests sort first with the white wing-flash egg and a tinted row; building shows an ember-ringed egg; waiting eggs dashed. Legend under the ledger.
FORM: Nest Record (ornithologists' nest record cards), position 3 on the re-rolled list; seed: seed:1e0bd10f7a2609a2. Raises: fixed-scale egg slots on one baseline; pen-ring on the focused row, strike on seen done.
SIGNATURE: Tickets as eggs, one egg per Ticket, state read from egg alone; motion grammar: a single slow ember pulse on the building egg, off under reduced motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
